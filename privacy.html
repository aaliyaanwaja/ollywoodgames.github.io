Privacy policy: One-Man Team

Draft. This describes how the current build behaves. The owner must review it, add a contact address, and update it before any change that adds ads, analytics or accounts.

Last updated: 21 November 2026

What the game collects

Nothing. One-Man Team has no accounts, no advertising, no analytics and no third-party trackers. It does not ask for, read or send any personal information.

What is stored on your device

Your progress (which moves you have completed, your stars and best times) and your sound and vibration settings are saved in your device's local storage so the game can remember them. This data never leaves your device. Clearing the game's data, or choosing "Reset progress" in the game, removes it.

Network use

The web version downloads the game's own files from this site and keeps a copy so it can run offline. The site is hosted on GitHub Pages; GitHub may log technical information such as IP addresses when files are requested, as described in GitHub's privacy statement.

Children

The game contains no content that requires an age restriction and collects no data from anyone, including children.

Changes

If the game ever adds advertising, analytics or online features, this policy will be updated before that version is released.
